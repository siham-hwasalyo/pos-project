##  Description
This is a simple Point of Sale (POS) system developed using HTML, CSS, Bootstrap, and JavaScript (DOM manipulation).  
It allows users to add products, manage a cart, and calculate the total price automatically.

---

##  Technologies Used
- HTML5  
- CSS3  
- Bootstrap  
- JavaScript (DOM)

---

##  Features
- Add products dynamically  
- Remove products from cart  
- Automatic total calculation  
- Quantity management  
- Simple and responsive UI  

---

##  How to Run
- Download or clone the project  
- Open the folder  
- Run `index.html` in your browser
